# Школа стрижки — Android-приложение

Kotlin + Jetpack Compose. Разделы: Женские / Мужские / Детские стрижки.
Подразделы: Короткие, Средние, Длинные волосы (+ Борода у мужских). Есть «Избранное».

## Как собрать
**Вариант 1 — Android Studio:** File → Open → папка проекта → дождаться синхронизации → Run ▶ (или Build → Build APK).
**Вариант 2 — GitHub:** загрузить проект в репозиторий; во вкладке Actions → «Build APK» появится готовый `app-debug.apk`.

## Как добавлять уроки
Файл `app/src/main/assets/videos.json` — массив записей. Сейчас он пустой (`[]`).

```json
[
  {
    "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
    "title": "Название урока",
    "channel": "Название канала",
    "language": "ru",
    "durationMin": 95,
    "section": "women",
    "sub": "medium"
  }
]
```

| поле | значения |
|---|---|
| `section` | `women`, `men`, `kids` |
| `sub` | `short`, `medium`, `long`, `beard` (`beard` — только для `men`) |
| `url` или `id` | ссылка на YouTube или 11-символьный ID — достаточно одного |
| `durationMin` | длительность в минутах (необязательно) |
| `thumbnail` | свой URL превью — нужен только для видео не с YouTube |

- Превью для YouTube подтягивается автоматически.
- Видео с YouTube играют внутри приложения (есть полный экран). Если встроенный плеер не работает (автор запретил встраивание) — показывается превью и открытие по ссылке.
- Видео не с YouTube открываются по ссылке во внешнем приложении/браузере.
- Ролики короче `MIN_LESSON_MINUTES` (20 мин, см. `VideoRepository.kt`) скрываются — если `durationMin` указан.
